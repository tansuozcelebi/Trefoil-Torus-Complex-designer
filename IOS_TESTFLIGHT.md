# iPhone app via TestFlight

The web app is wrapped in a native iOS shell with [Capacitor](https://capacitorjs.com)
(`capacitor.config.json`, `ios/`). The **iOS TestFlight** workflow
(`.github/workflows/ios-testflight.yml`) builds it on a GitHub macOS runner,
signs it and uploads it to TestFlight on every push to `main` (and on demand from
the Actions tab). Until the secrets below exist the workflow skips with a warning.

| | |
|---|---|
| App name | Trefoil Designer |
| Bundle ID | `com.kreamakina.trefoil` (change `appId` in `capacitor.config.json` and `PRODUCT_BUNDLE_IDENTIFIER` in `ios/App/App.xcodeproj/project.pbxproj` together) |
| Version | `package.json` version (e.g. 1.2.1) |
| Build number | `100 + GitHub run number` |

## One-time setup

1. **Apple Developer Program** membership (paid) for the team that will own the app.
2. **App record** — in [App Store Connect](https://appstoreconnect.apple.com) → Apps → **+** → New App:
   platform iOS, name *Trefoil Designer*, bundle ID `com.kreamakina.trefoil`
   (register it first under Certificates, Identifiers & Profiles → Identifiers if it is not listed), any SKU.
3. **API key** — App Store Connect → Users and Access → Integrations → App Store Connect API →
   Team Keys → **+**, access **Admin** (needed so Xcode can create the distribution
   certificate and profile in the cloud). Download the `.p8` file (only possible once) and note
   the **Key ID** and the **Issuer ID**.
4. **Team ID** — developer.apple.com → Account → Membership details.
5. **GitHub secrets** — repository Settings → Secrets and variables → Actions → New repository secret:

   | Secret | Value |
   |---|---|
   | `APPLE_TEAM_ID` | Team ID, e.g. `AB12CD34EF` |
   | `ASC_KEY_ID` | API Key ID |
   | `ASC_ISSUER_ID` | API Issuer ID |
   | `ASC_KEY_P8` | full text of the `.p8` file, including the `BEGIN`/`END PRIVATE KEY` lines |

6. Run **Actions → iOS TestFlight → Run workflow**. After upload, Apple processes the build
   for a few minutes; it then appears under the app's **TestFlight** tab.
7. **Testers** — TestFlight tab → Internal Testing → add a group and testers (team members,
   no review needed). External testers need a short Beta App Review first.
   Testers install the **TestFlight** app on the iPhone and accept the invitation.

## Local development (macOS)

```sh
npm run build && npx cap sync ios   # copy dist/ into the iOS project
npx cap open ios                    # open in Xcode, pick a device, Run
```

`ios/App/App/public` is generated by `cap sync` and is not committed.
